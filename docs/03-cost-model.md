# 실제로 나가는 돈 계산하기

보증금과 월세만 보면 어느 집이 싼지 알 수 없습니다.
**한 달에 실제로 얼마가 나가는지**를 여섯 항목으로 계산합니다.

```
보증금에 묶이는 돈 + 대출 이자 + 월세 + 관리비 + 교통비 + 이사·중개비
```

**원칙 하나: 미래 비용을 맞히려 하지 않습니다. 계산에 쓴 가정을 다 밝힙니다.**

> 2026년 7월 기준 전세대출 평균 4.0%로 계산했습니다.
> 실제 금리는 심사 결과에 따라 다를 수 있습니다.

---

## 1. 환산식

거주 기간을 `T`개월로 가정할 때, 월 실질 주거비는 다음의 합입니다.

| # | 항목 | 계산 |
|---|---|---|
| 1 | 보증금 기회비용 | `자기자금 보증금 × 기회비용률(연) ÷ 12` |
| 2 | 대출 이자 | `대출 원금 × 대출금리(연) ÷ 12` |
| 3 | 월세 | 그대로 |
| 4 | 관리비 | `고정 관리비 + 별도 항목 추정` |
| 5 | 교통비 | `Σ(1인당 왕복 요금 × 월 근무일수)` — 2인 합산 |
| 6 | 초기비용 월분할 | `(중개보수 + 이사비 + 입주청소 + 부대비용) ÷ T` |

```
월 실질 주거비 = ① + ② + ③ + ④ + ⑤ + ⑥
```

### 보증금을 둘로 쪼개는 이유

보증금 전액에 기회비용을 매기면 **대출 부분이 이중 계산**됩니다.
대출로 조달한 부분은 ②의 이자로 이미 비용이 잡히므로,
①의 기회비용은 **자기자금 부분에만** 적용합니다.

```
보증금 = 자기자금(→ ① 기회비용) + 대출금(→ ② 이자)
```

이 구분이 전세와 월세를 공정하게 비교하는 지점입니다.

### 교통비를 1인당으로 계산하는 이유

여섯 항목 중 **교통비만 사람마다 값이 다릅니다.**

| 항목 | 단위 |
|---|---|
| ①②③④⑥ | 가구 — 한 명이 입력하면 끝 |
| ⑤ 교통비 | **개인** — 2인이면 출근지 2개 |

그래서 이 항목이 2인 확장의 자연스러운 명분이 됩니다.
비용을 정확히 계산하려는 것만으로 "상대 출근지도 넣어주세요"가 필요해집니다.
→ `decisions/0002-two-person-premise.md`

### 기회비용률을 무엇으로 잡을지가 결론을 뒤집습니다

이 모델에서 가장 큰 판단이며, **이제 격차의 크기가 실측됩니다.**

| 선택 | 값 (2026 기준) | 논리 | 결과 |
|---|---|---|---|
| **예금금리** (기본값) | **3.08%** | "안 썼으면 예금에 넣었을 돈" | 전세가 유리해 보임 |
| 대출금리 | 4.00% | "그 돈이 없으면 빌려야 하는 값" | 월세가 유리해 보임 |
| 투자수익률 | 사용자 입력 | "다른 데 투자했을 기회" | 가정에 따라 크게 흔들림 |

**격차는 약 0.92%p입니다.** 보증금 2억 기준으로 **연 184만원, 월 약 15만원** 차이가 납니다.
전세와 월세의 우열이 이 선택 하나로 뒤집힐 수 있는 크기입니다.

**기본값은 예금금리(3.08%)로 잡되, 사용자가 바꿀 수 있게 합니다.**
가장 보수적인 값을 기본으로 두고 그것이 가정임을 밝히는 쪽이 방어 가능한 설계입니다.

### 금리는 고정값이 아닙니다

두 금리 모두 최근 상승 추세입니다 — 저축성수신금리는 2026년 5월 2.93% → 6월 3.08%로
한 달에 0.15%p 올랐습니다. **기본값을 코드에 상수로 박으면 안 됩니다.**
분기 1회 갱신 또는 API 연동을 전제로 설계하고, 화면에는 **적용 시점**을 함께 표기합니다.

> 2026년 6월 기준 예금금리 3.08%를 적용했습니다.

모든 숫자 옆에 전제가 따라붙습니다. 예외 없습니다.

> 2026년 7월 기준 전세대출 평균금리 4.0%(범위 3.8~4.2%)를 적용한 추정치이며,

> 보증금 기회비용은 2026년 6월 기준 예금금리 3.08%로 계산했습니다.
> 중개보수는 서울시 상한요율 기준 최대치이며 협의로 낮아질 수 있습니다.

### 금지 표현

| 쓰지 않음 | 대신 |
|---|---|
| "월 실질 주거비는 92만원입니다" | "월 약 92만원으로 추정됩니다 (전제 보기)" |
| "A가 더 저렴합니다" | "이 전제에서는 A가 월 12만원 낮습니다" |
| "대출 가능액 1억 2천" | "심사 전 예상 한도이며 실제와 다를 수 있습니다" |

전제 공개는 정직함의 문제만이 아닙니다.
**금리·한도를 단정해 제시하면 유사 금융자문 소지가 생깁니다.**
전제를 드러내는 설계가 그 방어선과 정확히 같은 자리에 있습니다.

## 4. 이미 있는 것과 새로 만드는 것

총비용 계산 자체는 국내에 이미 여러 개 있습니다. 새로 만들 이유가 없습니다.

| 항목 | 선행 사례 |
|---|---|
| ① 보증금 기회비용 | 바로계산 — 매매·전세·월세 2년/4년 총비용(이자·세금·기회비용) |
| ② 대출 이자 | 핀다, EZB 부동산계산기 |
| ③ 월세 | 전 계산기 공통 |
| ④ 관리비 | 부분적 — 세부 내역은 어디에도 없음 |
| **⑤ 교통비** | **없음** |
| **⑥ 초기비용** | **없음** |

**우리가 추가하는 것은 ⑤와 ⑥ 두 개뿐입니다.**
①②③은 검증된 계산식을 따르고, ④는 데이터 한계를 전제로 밝힙니다.

그리고 ⑤가 이 모델에서 유일하게 2인을 필요로 하는 항목입니다.

## 5. 미해결

- **관리비 별도 항목**을 어디까지 추정할지. 수도·난방·인터넷은 세대별 편차가 커서
  평균으로 계산하면 오차가 큽니다. 범위(min~max)로 제시하는 안을 검토 중.
- **교통비 계산 소스.** 대중교통 요금 API 또는 지도 API 경로 결과 중 무엇을 쓸지 미정.
- 자차 통근 사용자의 ⑤ 계산 (유류비 + 주차비). 초기 범위에서는 제외.
- **이사비·입주청소 신뢰도가 중간입니다.** 업체 블로그와 비교 사이트를 종합한 값이라
  공적 통계가 아닙니다. 범위로만 제시하고 단일 추정값을 내지 않습니다.
- **금리 갱신 주기와 방법.** 분기 수동 갱신 vs API 연동 미정.
  한국은행 ECOS와 한국주택금융공사 공시가 후보.
