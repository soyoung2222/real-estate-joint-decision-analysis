## 판정 방식


| 항목       | 결정                                      |
| -------- | --------------------------------------- |
| 판정 등급    | **둘 다 충족 / 한쪽만 충족 / 둘 다 불충족 + `확인 필요`** |
| 총점       | **만들지 않음.** 조건 간 합산 금지                  |
| 조건 소속    | **사람에 저장** (매물이 아니라)                    |
| 입력 개수    | **사람당 4번** — 출근지 · 예산 · 필수 2개           |
| 필수 슬롯    | **2개 고정** (상한)                          |
| 입력 방식    | **점진적 공개** — 1단계 출근지+예산 → 즉시 결과 → 조건 추가 |
| 1단계 표시   | **값만** (임계값이 없으므로). 2단계부터 판정            |
| 이동수단     | **받음** — 출근지 화면 토글. 기본값 대중교통            |
| 조건 표시 순서 | **예산 → 통근 → 필수① → 필수② → 선호 → 확인** 고정    |
| 미충족 정렬   | **위로 올리지 않음** — 좌우 비교가 깨짐               |
| 확인 필요 상한 | **3개**                                  |
| 확인 필요 배지 | 후보 목록 최소 · 상세 인라인 · **질문 카드 크게**        |

## 사용자 데이터 수집 범위


| 항목                    | 쟁점                                             |

| 항목                      | 왜 막히나                       |
| ----------------------- | --------------------------- |
