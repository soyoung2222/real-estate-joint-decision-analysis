## A · 일화

**표본이 작고 선택 편향이 있다. 방향 신호로만 쓴다.**

| # | 관찰 | 표본 | 무엇에 쓰나 | 무엇에 못 쓰나 |
|---|---|---|---|---|
| **A1** | **2인 이상이 함께 집을 구하면 더 오래 걸린다** | 사용자 주변 지인 (n 미상, 비체계적) | **H2-b의 방향 신호.** 인터뷰 질문 설계의 출발점 | **H2-b를 확정으로 올리는 근거 ✗**<br>발표에서 “둘이면 오래 걸립니다” 단정 ✗ |
| A2 | “그 집 어때?” → “음… 그냥 별로” 로 대화가 끝난다 | 프로젝트 초기 관찰 (n 미상) | 문제 서술의 구체화 | 빈도·보편성 주장 ✗ |
| A3 | 찜한 뒤 카톡·지도·계산기·메모장을 오간다 | 동일 | AS-IS journey 구성 | 단계별 소요 시간 주장 ✗ |

### A1을 어떻게 다루는가

이 관찰은 **버리지 않는다.** 다만 승격도 하지 않는다. 세 가지 이유다.

**① 표본이 비체계적이다.** 몇 명인지, 어떤 관계였는지, 무엇과 비교해 “더 오래”인지가 없다.
F1의 2.5개월은 1인 기준 실측이고, A1은 그것과 직접 비교할 수 있는 형태가 아니다.

**② 원인이 우리 가설과 다를 수 있다.** 이게 결정적이다.

```
관찰:  "둘이면 오래 걸린다"

가능한 원인
  ① 조건이 충돌해서 결정을 못 함        ← 우리 가설(H2-b)
  ② 둘의 일정을 맞추기 어려워 방문이 늦음   ← 교란 요인
  ③ 결정권자가 둘이라 승인 단계가 하나 더 늚
  ④ 예산 합의 자체가 선행 과제라 시작이 늦음
```

**②③④가 참이어도 “둘이면 오래 걸린다”는 참이다.** 그런데 우리 서비스는 ①만 푼다.
원인을 구분하지 않으면 **문제는 실재하는데 우리 해법이 빗나가는** 상황이 된다.

**③ 그래서 이 관찰은 인터뷰를 구체화한다.** 무엇을 물어야 할지가 생겼다.

| 물어볼 것 | 무엇을 가릅니까 |
|---|---|
| “혼자 구할 때와 비교해 얼마나 더 걸렸나요?” | A1의 크기 |
| “가장 오래 멈춰 있던 순간은 언제였나요?” | ①~④ 중 어디 |
| “그때 무엇 때문에 진행이 안 됐나요?” | **원인 구분 — 핵심 문항** |
| “의견이 갈렸던 조건이 있었나요? 어떻게 정했나요?” | ①의 존재와 해결 방식 |
| “일정을 맞추기 어려웠던 적은요?” | ②를 명시적으로 분리 |

**H2-b의 통과 기준을 갱신한다.**

```
기존:  "상대와 의견이 갈려 결정이 지연된 경험"이 과반
갱신:  위 + 지연 원인을 물었을 때 <조건 충돌>이 <일정 조율>보다 많이 지목될 것
```

일정 조율이 더 많이 나오면 **우리가 푸는 문제가 그 사람들의 병목이 아니다.**
그 경우 F7(방문 후보 합의) 다음에 일정 조율 기능이 붙어야 하는지를 다시 판단한다.

## 발표에서 쓸 수 있는 문장 · 없는 문장

| ✅ 쓸 수 있다 | ❌ 쓰면 안 된다 |
|---|---|
| “전세 계약자는 2.5개월간 4.1곳을 봅니다” (F1) | “둘이 구하면 두 배 걸립니다” — **측정 안 됨** |
| “1인용 임장 기록 앱이 20개 넘게 있습니다” (F2) | “관심매물의 60%가 방치됩니다” — **내부 데이터** |
| “2인 초대는 결혼준비 앱에서 이미 작동합니다” (F3) | “초대 수락률이 70%일 것으로 예상됩니다” — **근거 없음** |
| “의료 분야에는 총점 없이 옵션을 제시하는 국제 표준이 있습니다” (F8) | “국내에 경쟁자가 없어 시장이 열려 있습니다” — **미개척 ≠ 수요** |
| “저장 이후 단계가 전부 앱 밖에서 일어납니다” (I1) | “둘이라서 결정이 늦어집니다” — **H2-b 미검증** |
| “2인이면 더 오래 걸린다는 이야기를 들었고, 그래서 인터뷰로 확인하려 합니다” (A1) | “2인이면 더 오래 걸립니다” — **일화를 사실로** |

마지막 줄이 이 문서의 존재 이유다. **같은 관찰도 어떻게 말하느냐로 등급이 갈린다.**
