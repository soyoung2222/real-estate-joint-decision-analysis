# 실제로 나가는 돈 계산하기

보증금과 월세만 보면 어느 집이 싼지 알 수 없습니다.
**한 달에 실제로 얼마가 나가는지**를 여섯 항목으로 계산합니다.

```
보증금에 묶이는 돈 + 대출 이자 + 월세 + 관리비 + 교통비 + 이사·중개비
```

**원칙 하나: 미래 비용을 맞히려 하지 않습니다. 계산에 쓴 가정을 다 밝힙니다.**

> 2026년 7월 기준 전세대출 평균 4.0%로 계산했습니다.
> 실제 금리는 심사 결과에 따라 다를 수 있습니다.

## 1. 환산식

거주 기간을 `T`개월로 가정할 때, 월 실질 주거비는 다음의 합입니다.

| # | 항목 | 계산 |
|---|---|---|
| 1 | 보증금 기회비용 | `자기자금 보증금 × 기회비용률(연) ÷ 12` |
| 2 | 대출 이자 | `대출 원금 × 대출금리(연) ÷ 12` |
| 3 | 월세 | 그대로 |
| 4 | 관리비 | `고정 관리비 + 별도 항목 추정` |
| 5 | 교통비 | **대중교통** `Σ(1인당 왕복 요금 × 월 근무일수)` — 2인 합산<br>**자차** `Σ(편도거리 × 2 × 근무일수 ÷ 실연비 × 유가 + 통행료)` — §5 |
| 6 | 초기비용 월분할 | `(중개보수 + 이사비 + 입주청소 + 부대비용) ÷ T` |

```
월 실질 주거비 = ① + ② + ③ + ④ + ⑤ + ⑥
```

### 보증금을 둘로 쪼개는 이유

보증금 전액에 기회비용을 매기면 **대출 부분이 이중 계산**됩니다.
대출로 조달한 부분은 ②의 이자로 이미 비용이 잡히므로,
①의 기회비용은 **자기자금 부분에만** 적용합니다.

```
보증금 = 자기자금(→ ① 기회비용) + 대출금(→ ② 이자)
```

이 구분이 전세와 월세를 공정하게 비교하는 지점입니다.

### 교통비를 1인당으로 계산하는 이유

여섯 항목 중 **교통비만 사람마다 값이 다릅니다.**

| 항목 | 단위 |
|---|---|
| ①②③④⑥ | 가구 — 한 명이 입력하면 끝 |
| ⑤ 교통비 | **개인** — 출퇴근하는 사람 수만큼 |

그래서 이 항목이 2인 확장의 자연스러운 명분이 됩니다.
비용을 정확히 계산하려는 것만으로 "상대 출근지도 넣어주세요"가 필요해집니다.
→ `decisions/0002-two-person-premise.md`

### 출퇴근을 안 하는 사람은 ⑤에서 빠집니다

**출근지가 없는 사람이 있습니다** — 재택·무직·전업·은퇴·학생.
그 사람의 교통비는 0이 아니라 **계산 대상이 아닙니다.**

```
둘 다 출퇴근    ⑤ = A 교통비 + B 교통비
한 명만         ⑤ = 그 한 명의 교통비        ← 0을 더하지 않는다
아무도 안 함    ⑤ = 항목 자체를 표시하지 않는다
```

**0원으로 적으면 "교통비가 안 드는 집"처럼 읽힙니다.** 실제로는 통근 목적의
이동이 없을 뿐이고, 그건 집의 속성이 아니라 사람의 상황입니다.
같은 이유로 **매물 간 비교에 영향을 주지 않습니다** — 어느 집을 골라도 같은 값이므로
그 사람에게는 ⑤가 비교 축이 되지 못합니다.

> 화면 문구 — "B는 출퇴근을 하지 않아 교통비를 넣지 않았습니다."
> 전제를 밝히는 원칙(§3)이 여기에도 그대로 적용됩니다.

## 4. 이미 있는 것과 새로 만드는 것

총비용 계산 자체는 국내에 이미 여러 개 있습니다. 새로 만들 이유가 없습니다.

| 항목 | 선행 사례 |
|---|---|
| ① 보증금 기회비용 | 바로계산 — 매매·전세·월세 2년/4년 총비용(이자·세금·기회비용) |
| ② 대출 이자 | 핀다, EZB 부동산계산기 |
| ③ 월세 | 전 계산기 공통 |
| ④ 관리비 | 부분적 — 세부 내역은 어디에도 없음 |
| **⑤ 교통비** | **없음** |
| **⑥ 초기비용** | **없음** |

**우리가 추가하는 것은 ⑤와 ⑥ 두 개뿐입니다.**
①②③은 검증된 계산식을 따르고, ④는 데이터 한계를 전제로 밝힙니다.

그리고 ⑤가 이 모델에서 유일하게 2인을 필요로 하는 항목입니다.

## 5. 자차 통근 비용

이동수단을 자차로 고르면 교통비 계산이 달라진다. **변동비만 넣는다.**

```
자차 월 통근비 = 유류비 + 통행료

유류비 = 편도거리(km) × 2 × 월 근무일수 ÷ 실연비(km/L) × 유가(원/L)
```

### 고정비를 넣지 않는 이유

보험료·감가상각·정비비는 **집을 어디로 가든 똑같이 나간다.**
차를 이미 갖고 있는 사람에게 이 값들은 매물 비교에 아무 차이를 만들지 않는다.
여기서 재려는 것은 **"이 집으로 가면 교통비가 얼마나 달라지는가"**이므로 변동비만 넣는다.

| 항목 | 넣나 | 이유 |
|---|---|---|
| 유류비 | ✅ | 거리에 비례 — 매물마다 다르다 |
| 통행료 | ✅ | 경로에 따라 다르다 (기본 0) |
| 직장 주차비 | ❌ | **집 위치와 무관** |
| 집 주차비 | △ | 관리비에 포함되면 ④에서 이미 계산됨. 별도면 그쪽에 |
| 보험·감가·정비 | ❌ | **거리와 무관하거나 2차적** |

### 계산 예시

편도 15km, 월 20일 근무, 실연비 10km/L, 유가 1,864원/L:

```
월 주행거리 = 15 × 2 × 20 = 600 km
유류비      = 600 ÷ 10 × 1,864 = 111,840원
                                 ≈ 월 11.2만원 (1인)
```

같은 조건을 대중교통(왕복 3,000원 가정)으로 바꾸면 월 6만원이다.
**자차가 약 1.9배 비싸고, 그 차이가 실부담에 그대로 반영된다.**

### 신뢰도 — 실연비가 가장 약하다

| 값 | 신뢰도 | 비고 |
|---|---|---|
| 유가 1,864원/L | 높음 | 오피넷 1차 출처. **주간 변동이 커 갱신 전제** |
| 근무일수 20일 | 확정 | 기존 전제와 동일 |
| **실연비 10km/L** | **낮음** | 준중형 공인 14 × 달성률 75%. **차종·주행조건 편차가 크다** |
| 통행료 0원 | 기본값 | 사용자가 입력하면 반영 |

**실연비는 사용자가 조정할 수 있게 한다.** 하이브리드(18~20km/L)와 대형 SUV는
두 배 이상 차이 나므로 기본값 하나로 덮을 수 없다.

### 화면 문구

> 자차 통근은 **유류비와 통행료만** 계산했습니다.
> 2026년 8월 전국 평균 휘발유 1,864원/L, 연비 10km/L 기준 추정치이며,
> 보험료·감가상각처럼 집 위치와 무관한 비용은 넣지 않았습니다.

**금지 표현**은 §3과 동일하다 — "월 11만원입니다"가 아니라 "월 약 11만원으로 추정됩니다".

## 6. 미해결

- **관리비 별도 항목**을 어디까지 추정할지. 수도·난방·인터넷은 세대별 편차가 커서
  평균으로 계산하면 오차가 큽니다. 범위(min~max)로 제시하는 안을 검토 중.
- ~~교통비 계산 소스~~ → ✅ **해소.** 네이버 내부는 지도 대중교통 엔진, 팀 프로토타입은
  ODsay LAB Basic(일 1,000 호출 무료). → `10-data-integration.md` §4-2
- ~~자차 통근 ⑤ 계산~~ → ✅ **해소.** §5에 변동비 모델(유류비 + 통행료)로 명세됨.
  **주차비는 넣지 않는다** — 직장 주차비는 집 위치와 무관하고, 집 주차비는 ④ 관리비에 잡힌다.
- **이사비·입주청소 신뢰도가 중간입니다.** 업체 블로그와 비교 사이트를 종합한 값이라
  공적 통계가 아닙니다. 범위로만 제시하고 단일 추정값을 내지 않습니다.
- **금리 갱신 주기와 방법.** 분기 수동 갱신 vs API 연동 미정.
  한국은행 ECOS와 한국주택금융공사 공시가 후보.
